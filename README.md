React + Tailwind + Supabase chat app with neumorphic UI.

## Features
- Modern glassmorphism/neumorphic chat UI (glow bubbles, shimmers)
- Fully responsive (mobile/desktop)
- Real-time messages, media (image/video/voice/location)
- CRUD (send/edit/delete/pin)
- Typing indicators, reactions ready
- Error toasts for send/upload/DB issues


-----

## 🌌 Apa itu ChatSSLock?

**ChatSSLock** bukan sekadar aplikasi pengiriman pesan instan biasa; ia adalah sebuah manifestasi dari kebebasan digital dan kedaulatan privasi di era pengawasan massal. Dibangun di atas fondasi arsitektur **Modern UI** yang sangat estetik oleh tim **Visualcodepo**, ChatSSLock hadir sebagai solusi bagi mereka yang menuntut transparansi teknologi tanpa mengorbankan keindahan visual.

Dalam ekosistem ChatSSLock, setiap transmisi data diperlakukan sebagai entitas suci. Kami menggabungkan kecepatan sinkronisasi *real-time* berbasis **Supabase WebSockets** dengan protokol keamanan berlapis yang memastikan bahwa hanya pengirim dan penerima sah yang memiliki kunci untuk membuka gerbang informasi. Dengan antarmuka yang dihiasi *soft gradients*, animasi fluid dari **Framer Motion**, dan tata letak minimalis, ChatSSLock memberikan pengalaman pengguna yang tenang, fokus, dan sepenuhnya aman.

## ⚡ Keunggulan Utama (Core Pillars)

### 🛡️ 1. Military-Grade Privacy & Encryption
Setiap karakter yang Anda ketik, setiap citra yang Anda bagikan, dilindungi oleh algoritma enkripsi ujung-ke-ujung (E2E). Sistem kami tidak menyimpan jejak kunci di sisi server, memastikan bahwa percakapan Anda tetap menjadi milik Anda secara absolut.

### 👁️ 2. One-Time View Protocol (Ephemeral Media)
Fitur unggulan untuk berbagi data sensitif. Foto atau media yang dikirim dengan mode **1x View** akan terhapus secara otomatis dan permanen dari node jaringan segera setelah penerima melihatnya. Tidak ada residu data, tidak ada jejak digital.

### 🚀 3. Hyper-Sync Realtime Engine
Menggunakan infrastruktur *relay nodes* global, ChatSSLock meminimalisir latensi hingga ke titik terendah. Pesan tersampaikan secara instan melalui jalur WebSocket yang dioptimalkan khusus untuk efisiensi bandwidth tanpa mengurangi integritas data.

### 🎨 4. Modern Aesthetic & Cyber-Islamic Visuals
Desain yang adaptif dengan sentuhan *Cyber-Islamic Aesthetic*—penggabungan antara geometri modern dan fungsionalitas futuristik. Antarmuka yang responsif memastikan kenyamanan penggunaan baik di perangkat mobile maupun desktop dengan transisi yang mulus.

### 🧬 5. Decentralized Identity (Unique ID)
Identitas Anda tidak terikat pada nomor telepon atau data pribadi yang invasif. ChatSSLock menggunakan sistem **Unique ID** berbasis node yang memungkinkan Anda terhubung secara anonim namun tetap terverifikasi dalam jaringan aman kami.

## 🛠️ Stack Teknologi

Proyek ini dibangun dengan presisi menggunakan ekosistem pengembangan web modern:

* **Frontend:** React 18 & Next.js (App Router)
* **Styling:** Tailwind CSS (Custom Dark Theme & Fluid Gradients)
* **Animations:** Framer Motion (Orchestration & Gestures)
* **Backend/Database:** Supabase (PostgreSQL + Realtime Channel)
* **Storage:** Supabase Storage (Encrypted Buckets)
* **State Management:** React Context API & Custom Hooks
* **Icons:** Lucide React

## 🚀 Instalasi Lokal

```bash
# Clone repositori
git clone [https://github.com/Dikrey/ChatSSLock.git](https://github.com/Dikrey/ChatSSLock.git)

# Masuk ke direktori
cd ChatSSLock

# Install dependensi
npm install

# Setup Environment Variables (.env)
# VITE_SUPABASE_URL=your_project_url
# VITE_SUPABASE_ANON_KEY=your_anon_key

# Jalankan aplikasi
npm run dev
````
